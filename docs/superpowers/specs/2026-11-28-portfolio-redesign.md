# Portfolio redesign
## Direction
Extend the approved dark homepage, Interview index and Two Sum concept across the live site. A visitor should recognize Angad, find a project, or begin a lesson on their first screen. A learner should be able to explain a state change without reading trace instrumentation.

Use the deployed obsidian canvas, graphite surfaces, warm ink, muted text, rule, brand, accent and active tokens. Use Georgia for display headings, Geist for navigation and prose, IBM Plex Mono for code and indices. Reserve large typography and the red mesh for the personal homepage. Inside readers give the space back to the content. One hairline between groups; movement only for an action or state change.

## What a trace teaches
For Two Sum show the input with stable indices, one active element, the complement, and a value-to-index table. On a lookup frame expose the exact lookup line. Highlight insertion only after the trace records it. A return frame identifies both indices. For sliding windows show the boundaries, for stacks the top, for grids the dependency cells, for trees the current bounds, for BFS the frontier, for LRU the recency order and for SQL the joined rows.

Use verified execution frames as the source of truth. Supply a reviewed mapping from instrumented source locations to visible solver lines per approach; validate the mapping against its exact source revision and package. Keep raw source separately accessible. If a mapping is missing or mismatched, retain the verified transcript and original line link. Never invent intermediate execution steps.

Start paused. Previous, Next and Play/Pause share one cursor with the diagram, explanation and code. Preserve focus and announce manual steps succinctly. Reduced motion changes state immediately; the diagram remains understandable via labels and position. On phones place the current code line beside the explanation before the full listing. JavaScript-disabled readers get worked examples and linked transcripts.

Preserve source provenance, asset digests, routes and anchors, authenticated privacy, cached generation recovery, free-tier constraints, README identity and the 500-line non-test cap. Use the current combined release as the parity baseline. Recheck throttled homepage LCP with the established certification procedure. Production publication uses the existing reviewed release path.
